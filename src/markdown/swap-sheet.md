# Shift Swap Sheet

Request a shift swap, get coworker and manager sign-off, and keep a record of every trade.

## How to use

Complete one form per swap request. Fill in your original shift and the shift you want instead, name the coworker you're trading with, then get both signatures plus manager approval. File the completed sheet with your shift records.

**Note:** Check your workplace's swap policy before trading — some employers require manager pre-approval or restrict swaps between certain roles.

## Fields

- Your name
- Coworker trading with
- Date of request
- Unit / department
- Your original shift: date, start time, end time, shift type
- Shift you want instead: date, start time, end time, shift type
- Coworker's shift (giving away): date, start time, end time, shift type
- Reason for swap
- Employee signature / Coworker signature / Manager approval / Date approved

Keep the swap log table at the bottom as a running record of all trades.
