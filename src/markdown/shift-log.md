# Shift Log

Track your shifts by month. Print blank, fill in by hand, or complete on screen before printing to PDF.

## How to use

Write one row per shift. Enter the date, day of week, shift type (days, nights, evenings, weekends), start and end times, unpaid break minutes, and total hours worked. At the end of the month, add up the Total Hours column.

**Tip:** Use Shift Type to spot patterns across days/nights — useful when you're building a sleep schedule or checking your pay stub.

## Columns

| Column | What to record |
|--------|----------------|
| Date | Date of the shift |
| Day | Day of the week |
| Shift Type | Days, nights, evenings, weekends, etc. |
| Start Time | Shift start |
| End Time | Shift end |
| Breaks (min) | Unpaid break minutes |
| Total Hours | Hours worked this shift |
| Overnight? | Mark if the shift crosses midnight |

At month end: total up the Total Hours column.
